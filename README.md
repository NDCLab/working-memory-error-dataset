# Effects of Error and Conflict on Working Memory

## Project Goal
Cognitive control plays a crucial role in adaptive behavior and achieving one’s goals. At the same time, in practice, mechanisms of cognitive control never operate alone; they are utilized together with other cognitive functions. From behavioral dual-task studies, there is evidence showing different relationships between working memory and speeded conflict task performance when given together, depending on task specifics and stimuli characteristics (Oberauer, 2019; Moss et al., 2020; Muhmenthaler et al., 2023). Additionally, there is data reporting working memory performance impairment specifically related to errors committed in speeded conflict tasks (Wessel et al., 2022). This work is aimed to investigate relationships between cognitive control processes, such as performance monitoring and conflict processing, and working memory on a behavioral level.

## Background & Design
This project employs three distinct behavioral experiments to explore the interactions between working memory, error processing, and conflict resolution:

1.  **Dual WM-Flanker Task:** A dual-task paradigm combining a Working Memory task with a Letter Flanker task. Participants are presented with a sequence of letters (load 4 or 5) to remember. During the retention interval, they perform a Flanker task where they must identify the case (uppercase/lowercase) of a central target letter amidst congruent or incongruent flankers. Finally, they recall the memory sequence in order. This design allows for the examination of how conflict and errors in the Flanker task impact working memory retention.

2.  **Letter Flanker Task:** A standalone version of the Flanker task used in the dual-task experiment. Participants respond to the case of a central target letter surrounded by congruent or incongruent flankers. This serves as a control to establish baseline performance and conflict effects for the letter stimuli without the working memory load.

3.  **Number Flanker Task:** A variation of the Flanker task using number stimuli. Participants must judge whether a central target number is less than or greater than 5, while ignoring flanking numbers that may be congruent (associated with the same response) or incongruent (associated with the opposite response). This task generalizes the findings to a different stimulus domain (numerical magnitude).
